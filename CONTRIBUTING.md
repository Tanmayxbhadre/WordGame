# Contributing to WordShift

## Workspace Commands
- `npm run build:packages` — Build all shared TypeScript packages
- `npm run typecheck` — Typecheck all workspaces
- `npm test` — Run Vitest unit and integration suites
- `npm run dev:web` — Start Next.js dev server (`http://localhost:3000`)
- `npm run dev:mobile` — Start Expo dev server
