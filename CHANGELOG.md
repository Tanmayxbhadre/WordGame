# Changelog

## [1.0.0] - 2026-11-27
### Added
- Shared monorepo packages (`shared-types`, `ui-tokens`, `word-dictionary`, `game-engine`).
- Curated 12,796-word 4- and 5-letter English dictionary with difficulty metadata.
- Supabase PostgreSQL schema, strict RLS policies, and atomic `SECURITY DEFINER` RPCs.
- Next.js App Router web app with private rooms, real-time gameplay, practice mode, profile, and settings.
- Expo React Native mobile app sharing `@wordshift/game-engine` and Supabase Realtime.
- Vitest unit/integration tests and Playwright E2E specs.
